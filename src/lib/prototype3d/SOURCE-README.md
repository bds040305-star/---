# 제품 3D 분해 뷰어

사진을 참고한 시연용 모델입니다. 실측 3D CAD 또는 실제 내부 구조의 복원 모델이 아닙니다.

## 실행
VS Code에서 `dist` 폴더를 열고 `index.html`을 Live Server로 실행하세요.
HTML을 더블클릭하는 file:// 방식은 ES Module 보안 제한 때문에 지원하지 않습니다.
Three.js, GSAP, ScrollTrigger가 vendor 폴더에 포함되어 있어 외부 CDN 없이 실행됩니다.

## 조작
- 스크롤: 부품 분해 / 재조립
- 분해 진행 슬라이더: 원하는 분해 상태로 이동
- 드래그: 회전 (터치에서는 좌우 드래그, 세로 스와이프는 페이지 스크롤)
- 앞면 / 뒷면 / 옆면 / 전체 버튼: 시점 전환
- 캔버스에 키보드 초점을 두고 방향키: 회전, + / -: 확대 축소
- 조립 상태로 되돌리기: 분해 상태 및 시점 초기화

## 수정 위치
- dist/app.js: Three.js 부품 형상 및 GSAP / ScrollTrigger 동작
- part(이름, 조립 위치, 분리 이동량, 라벨 위치): 각 부품을 독립 그룹으로 생성
- dist/style.css: 화면 배치, 반응형, 부품 라벨
- dist/index.html: 문구와 UI

정확한 제품 재현이 필요하면 부품별로 분리된 GLB 모델로 교체하세요.
포함 라이브러리의 라이선스 고지를 유지하세요.
