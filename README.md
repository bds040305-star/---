# Wells Farm Mini — Sylva Style

실행 방법:

```bash
npm install
npm run dev
```

브라우저에서 터미널에 뜨는 localhost 주소를 열면 됩니다.
Chrome 개발자도구에서 390px 모바일 폭으로 보면 가장 정확합니다.

## 페이지

각 화면은 별도 페이지로 표시되며 상단 메뉴 또는 전체 메뉴로 이동합니다.
GitHub Pages에서 직접 열기와 새로고침을 지원하기 위해 해시 주소를 사용합니다.

- `/wells/#/` — 첫 소개 화면
- `/wells/#/products` — 팜이 안내와 Wide / Slim 제품 선택
- `/wells/#/structure` — 3D 제품 구조와 분해 체험
- `/wells/#/how-it-works` — 재배 시스템과 조작 방법
- `/wells/#/seed` — 채소 선택과 재배 모드 체험
- `/wells/#/support` — 공지와 고객센터 안내

`/wells/#/inside`는 제품 소개 페이지로 연결됩니다.
기기 설정 팝업을 닫아도 현재 페이지와 기기 설정은 유지됩니다.

## 로그인과 팜이 상담 체험

- `/wells/#/ai` — 팜이 대화 시작 화면
- `/wells/#/chat` — 주제 선택, 미니팜 상태, 물 보충 안내와 완료 체험
- `/wells/#/login` — 로그인, 이메일 형식 오류와 비밀번호 오류
- `/wells/#/login/complete` — 체험 로그인 완료
- `/wells/#/register` — 샘플 미니팜 이름과 채소 등록

로그인 화면의 **체험 계정 채우기**를 누른 뒤 로그인하면 완료 화면으로 이동합니다.
이메일·비밀번호는 서버에 전송하거나 브라우저 저장소에 저장하지 않습니다.
현재 탭의 체험 로그인 여부만 `sessionStorage`에 보관하며 로그아웃하면 삭제합니다.
간편 로그인·회원가입·비밀번호 변경은 안내 화면이며 실제 인증 서비스와 연결되지 않습니다.

기본 체험 모드의 팜이 상담은 정해진 안내와 체험 상태를 표시합니다.
실제 AI 대화는 [연결 안내](docs/fami-ai-setup.md)에 따라 Cloudflare Workers AI를 연결하면 사용할 수 있습니다.
기본 연결 방식에는 별도의 AI API 키가 필요하지 않으며 Cloudflare 계정이 필요합니다.
AI 모드에서는 질문·최근 대화·체험 기기 정보가 모델 서비스로 전송됩니다.
연결이 실패하면 정해진 답변으로 대체하지 않고 오류와 재시도 버튼을 표시합니다.
물 보충 완료는 체험 상태만 갱신합니다. 스마트 제어는 기존 기기 설정 팝업을 사용합니다.
대화는 현재 화면 세션의 메모리에만 유지되며, 전체 새로고침 시 초기화됩니다.
화면 속 회색 키보드 모형 대신 휴대폰의 실제 키보드를 사용합니다.
