# 웰스 미니팜 — 실제 텍스트와 하단 팝업

완성 화면 이미지를 페이지로 보여주던 구현을 제거하고 제목·본문·버튼·탭·아이콘·기기 설정·메뉴·상담 화면을 HTML/CSS/SVG로 다시 작성했습니다. 텍스트는 선택·검색할 수 있고 모바일 고해상도 화면에서도 선명하게 표시됩니다.

## 버튼 동작

- 메뉴, 제품 구조, 고객센터 이동
- Wide/Slim 제품 탭, 채소 선택과 재배 모드 연결
- 전원 ON/OFF, 온도 16~30°C, 조명 0~100%, 급수 ON/OFF
- 상추/루꼴라/청경채 재배 모드, 예약 시간 저장
- 잠금/해제: 잠겨 있는 동안 전원과 설정 변경 방지
- 5개 조작방법 탭과 해당 설정 팝업 연결
- 공지·문의·푸터 링크 안내 팝업, 고객센터 전화 연결
- AI 팜이 상담 소개와 메시지 입력 체험

실제 기기·AI·계정 서버는 연결되어 있지 않습니다. 설정은 현재 세션에서만 유지됩니다. 제공되지 않은 공지 원문·약관·공식 소셜 주소는 안내 팝업으로 표시합니다. Slim 제품의 개별 사진이 없어 별도 준비 중 표시를 사용합니다.

## 이미지와 선명도

제품·식물·캐릭터 사진은 업로드된 PNG에서 사진 영역을 추출했습니다. 원본 이미지 자체의 해상도는 제한되어 있으며 확대한다고 사진의 실제 디테일이 늘어나지는 않습니다. 제목과 설명 등 모든 UI 텍스트는 이미지에서 분리해 실제 글자로 다시 작성했습니다. 섹션별 캡처는 390px 폭에서 2배 해상도로 생성했습니다.

## 검증

프로덕션 빌드와 Chromium 모바일 UI 검증을 수행했습니다. 기본 레이아웃은 13개 섹션이며 스크린샷 이미지 위의 투명 클릭 영역을 사용하지 않습니다. 기기 설정, 잠금으로 변경 방지, 상품/채소 선택, 메뉴/상담/안내 팝업을 확인했습니다. 320px 모바일에서 가로 넘침이 없고 데스크톱에서는 모바일 폭 390px를 유지합니다.

## 구조 섹션: 첨부한 실제 3D 인터랙션

`인터렉션_구현.zip`의 Three.js 부품 모델로 기존 구형 이미지 기반 프로토타입을 교체했습니다. 페이지 스크롤로 분해·재조립하고, 좌우 드래그 또는 방향키로 회전합니다. + / - 키로 확대·축소할 수 있습니다. 분해 진행 슬라이더, 앞면·뒷면·옆면·전체 시점, 조립 상태 초기화도 연결했습니다.

제공된 모델의 부품 형상·재질을 사용하며, Three.js 등 동봉 라이브러리와 라이선스 고지를 보존했습니다. 외부 CDN 없이 동작합니다. 페이지를 벗어나면 렌더러·이벤트·GPU 자원을 정리하고 화면 밖에 있을 때는 렌더링을 멈춥니다.

사진을 참고한 시연용 모델로 실제 CAD나 실측 내부 구조의 복원 모델은 아닙니다. WebGL이 지원되지 않으면 안내가 표시됩니다.
